# Edge & Guard: Storm Duels (Demo)

A realistic-guard sword and bow duel game that runs in your browser. This is the **demo**: it includes only the first duels of each mission.
The full game (more duels, more enemies, full progression) is on itch.io: **alphazolozyro.itch.io**

## Play
Enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root). The game is `index.html`.

## Controls
A/D or arrows move · W jump · J smash · K slice · L slash · S shield · Q dash · E special · R second wind
On phones, use the on-screen buttons.
