# edge-and-guard-demo
Free playable demo of Edge &amp; Guard: Storm Duels, a realistic sword-and-shield duel game for your browser. Time your parries, dash, charge and use elemental weapons, then switch to archery trials with different bows. Touch controls and sound included. Demo covers the first two duels only. Full game on itch.io (alphazolozyro). All rights reserved.
